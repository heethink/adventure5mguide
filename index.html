📐 2D 평면 vs 3D 입체

일반 프린터는 가로(X축)와 세로(Y축)만 있는 납작한 종이 위에 잉크를 칠합니다. 하지만 3D 프린터는 위로 솟아오르는 높이(Z축)를 더해 진짜 공간을 차지하는 실물을 만듭니다.

🔥 글루건의 원리 (FDM 적층 방식)

미술 시간에 쓰는 글루건처럼 단단한 플라스틱 국수 가닥(PLA 필라멘트)을 200℃ 이상의 고열로 녹여 바닥부터 0.2mm씩 얇은 층을 층층이 쌓아 올려 완성합니다.

2. 입문자를 위한 11대 필수 용어 사전

기본적인 핵심 개념을 한눈에 알기 쉽게 정리했습니다.

🔥 노즐 (Nozzle) 부품

플라스틱을 녹여 국수 가닥처럼 뿜어내는 글루건 끝부분(0.4mm 구멍)입니다.

🧱 베드 (Bed) 부품

출력물이 흔들리지 않고 착 달라붙어 세워지는 따뜻한 바닥 기초판입니다.

🌽 필라멘트 (PLA) 재료

옥수수 전분 성분으로 냄새가 적고 안전한 대표적인 친환경 플라스틱 소재입니다.

🤖 익스트루더 (Extruder) 모터

필라멘트를 톱니바퀴로 꽉 쥐고 노즐 안으로 밀어 넣어주는 정밀 모터입니다.

📏 레이어 높이 (Layer) 품질

한 층씩 쌓는 두께(0.2mm 표준)로, 얇을수록 도자기처럼 매끄러워집니다.

🍯 인필 (Infill) 내부

속을 얼마나 채울지 정하는 비율(%)로, 15~20% 벌집 모양으로 채웁니다.

🪵 서포트 (Support) 지지대

공중에 뜬 부위가 무너지지 않게 받쳐주는 목발이며 출력 후 떼어냅니다.

⚖️ 베드 레벨링 기초공사

바닥판과 노즐 사이의 간격을 완벽하게 균일하도록 맞추는 수평 작업입니다.

🧵 리트랙션 (Retraction) 거미줄방지

노즐이 이동할 때 거미줄이 생기지 않게 필라멘트를 살짝 뒤로 당기는 동작입니다.

👒 브림 (Brim) 모자챙

바닥 테두리에 얇은 챙을 넓게 둘러 좁은 모델이 넘어지지 않게 고정합니다.

🛶 라프트 (Raft) 뗏목판

모델 아래에 두꺼운 플라스틱 뗏목 판을 깔아 작은 부품을 확실히 안착시킵니다.

3. 오픈소스 3D 모델 무료 다운로드 & 컴퓨터 파일 준비

싱기버스와 메이커월드에서 필요한 부품만 쏙 골라 다운로드하는 실제 UI 방법입니다.

🔵 싱기버스 (Thingiverse) 낱개 다운로드
  1. 상단 검색창(`Search Thingiverse`)에 영어로 입력 (예: `robot model`, `keychain`)
  2. 마음에 드는 사진 클릭 후 상세 페이지로 이동
  3. 사진 아래 탭 중 [Thing Files (숫자)] 클릭
  4. 필요한 부품(예: `body.stl`) 우측의 파란색 [↓] 다운로드 아이콘 콕 누르기
  5. 광고나 압축 파일 없이 순수 .stl 파일만 즉시 저장 완료!
Thingiverse 바로가기 ↗
🟣 메이커월드 (MakerWorld) STL 다운로드
  1. 검색창에 한글로 자유롭게 검색 (예: `피규어`, `드래곤`, `필통`)
  2. 원하는 모델 클릭 후 상세 정보 확인
  3. 주황색 Direct Print 버튼을 피하고 [Download STL] 또는 [Raw Model Files] 클릭
  4. 내 Adventurer 5M에서 자유롭게 조절 가능한 순수 3D 파일 확보!
  5. 슬라이서 프로그램 가상 베드로 드래그해서 넣기
MakerWorld 바로가기 ↗
📂 STL vs 3MF 차이점

STL (.stl): 뼈대 모양만 담긴 흑백 스케치북으로 세상 모든 슬라이서가 읽을 수 있는 기본 표준입니다.

3MF (.3mf): 모양, 색상, 내부 채움, 지지대 위치까지 압축해 담은 종합 선물세트로 용량이 가볍습니다.

🗜️ 윈도우 ZIP 압축 풀기 3단계

1. [다운로드] 폴더의 노란 지퍼 파일(.zip) 위에서 마우스 우클릭
2. 메뉴에서 [압축 풀기...] 클릭 후 하단 [압축 풀기] 버튼 누르기
3. 열린 일반 폴더 속 진짜 .stl 파일을 슬라이서로 드래그하기!

⚙️

4. 슬라이싱 프로그램 6단계 실습 마스터 코스

파일을 불러와서 USB에 저장하기까지의 완벽한 6단계 흐름입니다.

1단계 파일 불러오기

.stl 또는 .3mf 파일을 마우스로 잡아 슬라이서 가상 베드로 쏙 던져 넣습니다.

2단계 크기 조절 (Scale)

'균일 비율(Uniform Scale)'에 체크하고 찌그러지지 않게 크기를 조절합니다 (단축키 S).

3단계 서포트 설정

공중에 뜬 부위가 있다면 자동 서포트나 트리 서포트를 켭니다. 좁다면 브림도 체크!

4단계 슬라이스 실행

[슬라이스(Slice)] 버튼을 찰칵 눌러 컴퓨터가 식빵처럼 층별 이동 경로를 계산합니다.

5단계 층별 미리보기

우측 슬라이더 바를 내리며 1층부터 꼭대기까지 내부 벌집과 지지대를 눈으로 검사합니다.

6단계 시간 확인 & .gx 저장

출력 시간과 무게를 확인한 뒤 USB 드라이브로 .gx 파일로 저장합니다.

5. 슬라이서 실제 화면 구조 및 조작법

내가 쓰는 프로그램의 실제 버튼 위치를 확인해 보세요.

🛠️ FlashPrint 5 실제 버튼 배치
  • 왼쪽 상단 흰색 카드: [큐브+](파일 불러오기), [휴지통](삭제)
  • 오른쪽 짙은 세로 툴바: 시점(눈), 이동(십자), 회전(원형), 크기(대각선), 자르기, 복제, 자동배치, 서포트(나뭇가지)
  • 상단 중앙 버튼: [슬라이싱 시작] (모델을 불러오면 활성화)
  • 우측 레이어 슬라이더: 층별 단면 시뮬레이션 검사
💡 .gx 파일 저장의 비밀!

FlashPrint에서 저장할 때 생성되는 .gx 파일은 이동 명령서(.gcode) 맨 앞에 컬러 썸네일 사진을 함께 저장합니다. 그래서 USB를 Adventurer 5M에 꽂았을 때 화면에 내가 만든 모델 사진이 그대로 나타납니다!

🌿 OrcaSlicer / Flash Studio 실제 버튼 배치
  • 상단 탭 바: 준비 하기(디자인 배치) / 미리 보기(슬라이스 검사)
  • 상단 가로 툴바: [큐브+](파일 추가), [A](자동정렬), [F](바닥밀착), [S](크기조절)
  • 왼쪽 숨은 메뉴 열기(<): Printer(`Adventurer 5M`), Filament(`PLA`), [Support] 탭에서 Tree(auto) 선택!
  • 우측 상단 버튼: [플레이트 슬라이스] 클릭 후 G-code 내보내기
💎 디자이너 CAD 파일 (.step) 지원

OrcaSlicer 계열은 각진 삼각형 그물망으로 깨진 STL 대신, 매끄러운 .step 파일을 그대로 읽어와 훨씬 부드러운 곡면 출력을 완성합니다!

비교 항목 FlashPrint 5 (공식) OrcaSlicer / Flash Studio (오픈소스)
지원 확장자 .stl, .obj, .3mf, .fpp, .step .3mf, .stl, .step, .obj, .amf
사진 3D 변환 지원 (.jpg, .png 평면 사진을 3D 부조로 자동 변환) 미지원 (3D 전용 모델 파일만 지원)
기본 저장 형식 .gx (컬러 썸네일 사진 포함) .gcode (표준 명령서)
서포트 특징 기본 직선형 및 기본 트리 서포트 상처 없이 톡 떨어지는 스마트 트리 서포트 특화

6. 플래시프린트 vs 오르카-플래시포지 vs 플래시 스튜디오 차이

이름이 다양해서 헷갈렸던 세 프로그램의 역사와 차이점을 명쾌하게 정리했습니다.

1. 플래시프린트 (FlashPrint 5)
자체 개발 클래식 엔진

플래시포지사가 과거부터 독자 개발해 온 오리지널 프로그램입니다. 극도로 단순하고 쉬운 화면, .gx 썸네일 저장, 평면 사진 3D 부조 변환 기능이 장점입니다.

2. 오르카-플래시포지 (Orca-Flashforge)
OrcaSlicer 커스텀 버전

세계적인 오픈소스 OrcaSlicer를 플래시포지가 가져와 Adventurer 5M의 600mm/s 고속 출력과 모션에 맞게 튜닝한 프로그램입니다. (트리 서포트, 압력 제어 내장)

3. 플래시 스튜디오 (Flash Studio)
최신 리브랜딩 통합 명칭

'오르카-플래시포지'의 최신 공식 명칭입니다! 플래시포지가 앱과 PC 프로그램을 통합하면서 이름을 바꾼 것이며, 내부 기능과 화면은 오르카와 완전히 같습니다.

💡 한눈에 보는 프로그램 계보 정리

• 오르카-플래시포지 = 플래시 스튜디오 데스크톱 (같은 프로그램의 과거 이름과 현재 이름입니다.)
• FlashPrint 5: 가장 단순하고 쉬워서 기본 모형을 빠르게 뽑을 때 적합.
• Flash Studio (오르카-플래시포지): Adventurer 5M의 600mm/s 초고속 성능을 100% 발휘하고 트리 서포트로 정교한 피규어를 뽑을 때 추천!

7. 서포트 완전 정복 연구소

선형 vs 트리형 구분 기준과 아래가 비어 있어도 서포트가 필요 없는 3대 마법입니다.

🏛️ 선형 서포트 (Linear)

바닥부터 수직으로 쭉 올라가는 사각 기둥 형태입니다.

  • 알맞은 물건: 책상 밑바닥, 다리(Bridge) 천장, 사각 상자, 기계 부품
  • 특징: 튼튼하게 하중을 받치지만 떼어낼 때 도구가 필요하고 흉터가 남기 쉬움
🌿 트리 서포트 (Tree)

식물 줄기나 나뭇가지처럼 부드럽게 뻗어나가는 곡선 지지대입니다.

  • 알맞은 물건: 공룡, 로봇, 동물, 만화 캐릭터 인형 피규어
  • 특징: 끝부분만 살짝 닿아 손으로 톡 치면 상처 없이 떨어지며 재료·시간 절약

✨ 아래가 비어 있어도 서포트가 필요 없는 3가지 마법

📐 45도의 법칙

새 층이 아래층에 50% 이상 걸쳐지므로 완만한 경사는 서포트 없이 스스로 버팁니다 (원뿔, 컵).

🌉 브릿징 (Bridging)

양쪽 기둥 사이(10~50mm)를 가로지를 때 쿨링 팬이 공중에서 급속 냉각시켜 팽팽한 다리를 놓습니다.

⛩️ 자연 아치 (Arch)

둥근 터널이나 윗부분이 뾰족한 물방울 구멍은 양쪽 벽으로 힘이 분산되어 스스로 섭니다.

9. 안전 수칙 5계명 & 문제 해결 FAQ

안전 수칙을 지키고 문제가 생겼을 때 스스로 해결하는 비법입니다.

🚨 안전 수칙 5계명 (골든 룰)
  1. 노즐 화상 주의: 노즐은 200℃가 넘으니 절대 손을 대지 않습니다.
  2. 안전거리 유지: 모터와 헤드가 번개처럼 움직이니 손을 넣지 않습니다.
  3. 실내 환기 필수: 플라스틱이 녹을 때 창문을 열어 공기를 통하게 합니다.
  4. 강제 조작 금지: 작동 중 베드를 잡아당기지 않고 [정지] 버튼을 누릅니다.
  5. 도구 안전 취급: 스크래퍼나 니퍼를 쓸 땐 몸 반대쪽으로 밀며 주의합니다.
